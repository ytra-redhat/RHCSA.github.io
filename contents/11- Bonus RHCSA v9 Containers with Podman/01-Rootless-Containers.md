# Rootless containers

## Exam focus

- Run and inspect containers as a regular user.
- Understand user namespaces and per-user container storage.
- Use `podman ps -a`, `podman inspect`, and `podman info`.

## Useful starting command

```bash
podman ps -a
```

> Practice on a disposable RHCSA VM or snapshot. Verify the result rather than only the command exit status.
