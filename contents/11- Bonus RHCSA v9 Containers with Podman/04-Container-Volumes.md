# Container storage and volumes

## Exam focus

- Create named volumes and bind-mount host directories.
- Account for ownership and SELinux labels such as `:Z` and `:z`.
- Verify persistent data independently of the container lifecycle.

## Useful starting command

```bash
podman volume ls
```

> Practice on a disposable RHCSA VM or snapshot. Verify the result rather than only the command exit status.
