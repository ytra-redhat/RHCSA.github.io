# Container registries

## Exam focus

- Search configured registries and pull fully qualified image names.
- Review `/etc/containers/registries.conf` and user-specific configuration.
- Authenticate with `podman login` only when required.

## Useful starting command

```bash
podman search registry.access.redhat.com
```

> Practice on a disposable RHCSA VM or snapshot. Verify the result rather than only the command exit status.
