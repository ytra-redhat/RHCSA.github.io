# Legacy networking artefacts

## Exam focus

- Recognise older network-scripts configuration while preferring NetworkManager.
- Translate persistent settings into `nmcli` connection profiles.
- Verify address, route, DNS, autoconnect, and activation state.

## Useful starting command

```bash
nmcli connection show
```

> Practice on a disposable RHCSA VM or snapshot. Verify the result rather than only the command exit status.
