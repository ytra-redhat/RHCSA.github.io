# Kickstart

## Exam focus

- Build unattended installation files with required commands and package selections.
- Validate syntax where `ksvalidator` is available.
- Keep storage and network directives appropriate for the target VM.

## Useful starting command

```bash
ksvalidator /path/to/file.ks
```

> Practice on a disposable RHCSA VM or snapshot. Verify the result rather than only the command exit status.
